💭 Отзыв — это текст

А текст в Python называется строкой. Тип строки — str. Мы уже работали со строками, когда использовали input(), но сегодня разберём их по-настоящему глубоко.

Строка
Это последовательность символов: букв, цифр, пробелов, знаков препинания. В Python строка — это объект, состоящий из нескольких элементов-символов.
'Привет!' — строка из 7 символов.
'Ходили на бокс' — строка из 14 символов (включая пробелы).

У чисел есть операторы + − * /. У строк тоже есть свои инструменты. Например, можно узнать длину, взять часть или найти слово.

🤖
Готов? Тогда начнём с самого простого — узнаем, из скольких символов состоит отзыв. Это первое, что просит менеджер.

Считаем длину отзыва

Менеджер комплекса обещает скидку за длинные отзывы. Значит, первая задача — научиться считать символы.

len()
Это функция для получения длины строки, указанной в скобках. Возвращаемое значение — количество символов.
len('Привет') → 6

Первый кейс турфирмы

Отзыв: «Это потрясающее место!»

feedback = 'Это потрясающее место!'
length = len( feedback )
print ( length )
Вывод программы
22
📖 Разбор

Строка 'Это потрясающее место!' содержит 21 букву и 1 восклицательный знак. Итого 22 символа.

len() считает всё: буквы, цифры, пробелы, знаки препинания. Даже пробел — это отдельный символ.

🧠 Как это работает

В Python строка — это объект из символов. Каждый символ пронумерован. Первый символ — 0, второй — 1 и так далее. Пробелы и точки тоже считаются!

feedback[i]

feedback[0] → Х

⏱ 32–38 минут · 🔤 lower()

Хитрый регистр

Управляющий комплекса ищет отзывы со словом «уют». Байт уверенно запустил программу — и получил странный результат.

🤖
Смотри, в отзыве «Уютно!» слово точно есть! А программа говорит «не найдено». А в отзыве «Отель уютный» — нашлось! Почему так?
feedback1 = 'Уютно!'
feedback2 = 'Отель уютный'
position1 = feedback1 . find ( 'уют' )
position2 = feedback2 . find ( 'уют' )
Вывод программы
-1
6
Большая буква Уютно!
Маленькая буква уютный
🚨 Причина

Python различает заглавные и строчные буквы. Для него «У» и «у» — разные символы.

В первом отзыве слово начинается с заглавной, а мы искали строчную. Поэтому find() вернула -1.

Решение — функция lower()

lower()
Это функция, которая делает все буквы в строке маленькими. Исходная строка не меняется — возвращается новая.
'УЮТ'.lower() → 'уют'
'Отель Уютный'.lower() → 'отель уютный'
Было Уютно!
Стало уютно!

Правильный код:

feedback = 'Уютно!'
feedback = feedback . lower () ← приводим к нижнему регистру
position = feedback . find ( 'уют' )
Вывод программы
0
📌 Строки неизменяемы

lower() не меняет исходную строку — она возвращает новую. Поэтому обязательно присваивай результат:

feedback = feedback.lower()

Странная программа

Один из стажёров написал программу, считающую рейтинг качества обслуживания. Всё ли в ней правильно?

point1 = input( 'Оцените от 1 до 5 удобство гостиницы: ' )
point2 = input( 'Оцените от 1 до 5 еду ресторана: ' )
total = point1 + point2
print ( 'Общий рейтинг:' , total )

Что если гость введёт 3 и 4?

Вывод программы
Оцените от 1 до 5 удобство гостиницы: 3
Оцените от 1 до 5 еду ресторана: 4
Общий рейтинг: 34
🚨 Что произошло?

Программа не сломалась, но посчитала неправильно. Вместо 7 она вывела 34.

Причина: input() всегда возвращает строку. Даже если гость ввёл число, для Python это текст.

Когда между двумя строками стоит +, интерпретатор не складывает числа, а склеивает строки: '3' + '4' → '34'.

Кто такой интерпретатор

Интерпретатор
Это специальная программа, распознающая и исполняющая команды. При распознавании он ориентируется на типы данных.
Оператор + между строками — интерпретатор понял «склеить строки». Между числами — «сложить числа».

Как операторы работают с разными типами

ОператорДля строкДля чисел
+ Объединение строк Сумма чисел
* Повторение строки Произведение чисел

Примеры:

ПрограммаВывод
'Отличное' + ' место'Отличное место
3 * 'Круто! 'Круто! Круто! Круто!
'Отличное' * 'место'Ошибка
⚠️ Функции работают только со своим типом

Функция len() находит длину только строк. Найти длину числа ей не под силу — Python выдаст ошибку.

Как исправить программу со стажёром

Нужно явно указать интерпретатору, что он работает с числами. Для этого обернём input() в int():

point1 = int( input( 'Оцените удобство: ' ) )
point2 = int( input( 'Оцените еду: ' ) )
total = point1 + point2
Теперь всё правильно
Оцените удобство: 3
Оцените еду: 4
Общий рейтинг: 7

02 Первая и последняя буква 🌱

Спроси слово и выведи его первую и последнюю буквы.

💡 Подсказка

Первая буква — word[0]. Последняя — word[-1] (отрицательный индекс — с конца).

✅ Решение 
word = input("Введите слово: ")
print("Первая:", word[0])
print("Последняя:", word[-1])
03 Цитата про спортзал 🌱🌱

Дано: feedback = "Ходили на бокс. Хороший пляж". Вырежи только первую часть — до точки.

💡 Подсказка

Срез [0:14]. Символ под номером 14 — точка, он не входит.

✅ Решение 
feedback = "Ходили на бокс. Хороший пляж"

04 Ищем окрошку 🌱🌱

Спроси отзыв и проверь, упоминается ли в нём слово окрошка. Напечатай «Есть!» или «Нет».

💡 Подсказка

find() возвращает -1, если слова нет. Сравни результат с -1.

✅ Решение 
feedback = input("Отзыв: ")
pos = feedback.find("окрошка")
if pos != -1:
    print("Есть!")
else:
    print("Нет")
05 Уют в любом регистре 🌱🌱

Спроси отзыв, приведи к нижнему регистру и проверь, есть ли слово уют.

💡 Подсказка

Сначала feedback = feedback.lower(), потом ищи find("уют").

✅ Решение 
feedback = input("Отзыв: ")
feedback = feedback.lower()
if feedback.find("уют") != -1:
    print("Упоминается уют!")
else:
    print("Про уют не сказано")
06 Рекламная цитата 🌱🌱🌱

Спроси отзыв. Найди слово спортзал и напечатай 20 символов начиная с этой позиции.

💡 Подсказка

Найди позицию через find(), потом сделай срез [pos:pos+20]. Проверь, что слово вообще есть.

✅ Решение 
feedback = input("Отзыв: ")
pos = feedback.find("спортзал")
if pos != -1:
    quote = feedback[pos:pos+20]
    print("Цитата:", quote)
else:
    print("Про спортзал не сказано")
07 Отзыв задом наперёд 🌱🌱🌱

Спроси отзыв и напечатай его в обратном порядке.

Срез с шагом -1: s[::-1].

✅ Решение 
feedback = input("Отзыв: ")
reversed_feedback = feedback[::-1]
print(reversed_feedback)

input() возвращает строку. Оберни в int(), чтобы складывать числа.
