⏱ 0–6 минут · 💭 Проблема

Одна и та же работа — много раз

Байт снова в деле. Он получил заказ от центра «Успех» — помочь учителям разгрузиться от рутины. Первая задача: печатать фирменные этикетки для тетрадей учеников.

🤖
Учительница Ирина Петровна попросила: «Надо распечатать этикетку для каждой тетради. Сверху название центра, снизу — имя, курс, группа». Вот такую:
ЦЕНТР УСПЕХ Имя: ____ Курс: ____ Группа: _____

Если учеников десять — этикеток десять. И для каждой нужно печатать одни и те же четыре строки. Байт попробовал решить в лоб — напечатал четыре команды для каждого ученика:

amount = int(input('Число учеников: ')) for i in range(amount): print('ЦЕНТР УСПЕХ') print('Имя: ____') print('Курс: ____') print('Группа: _____')

Работает. Но есть две проблемы.

1 Повторы. Четыре строки print — одни и те же каждый раз, и в каждом новом проекте придётся писать снова.
2 Разрастание. Если завтра попросят печатать ещё и бланки заданий с такой же шапкой — код станет в два раза длиннее.
🤖
Если бы я мог упаковать эти четыре print в одну команду с именем, например print_label(), — я бы просто писал:
for i in range(amount): print_label()

Одна строка — а делает всё то же самое! Оказывается, так действительно можно. Такая «упаковка» называется функцией.

⏱ 6–14 минут · 📇 Что такое функция

Функция — это именованный блок команд

Ты уже пользовался функциями: print(), input(), len(). Но оказывается, можно сделать свою собственную.

Функция
Это именованный набор команд программы, который можно вызвать из любой её части по имени.
Мы уже знаем много функций: print() печатает, input() спрашивает, len() считает длину. Все они созданы заранее. Но можно сделать и свою.

Зачем нужны функции

1 Не повторять код. Один раз написали — используем много раз.
2 Понятное имя. print_label() понятнее, чем четыре строки подряд.
3 Легко менять. Поменяли шапку центра — исправили в одном месте, применилось везде.
4 Переиспользовать. Одну и ту же функцию можно вызывать в разных программах.

Как это выглядит

Вот так мы «упаковываем» наш код в функцию:

def print_label(): print('ЦЕНТР УСПЕХ') print('Имя: ____') print('Курс: ____') print('Группа: _____')

А вот так — вызываем её из основной программы:

print_label()
Что выведет
ЦЕНТР УСПЕХ
Имя: ____
Курс: ____
Группа: _____
🧠 Ключевое различие

def — это объявление функции. Мы говорим Python: «вот такая функция существует, вот что она делает». Но пока она не выполняется.

print_label() — это вызов функции. Только в этот момент Python заходит внутрь и выполняет все команды.

Объявить функцию можно один раз — а вызывать сколько угодно.

📖 Как это работает

Когда Python встречает print_label() — он прыгает внутрь функции, выполняет всё её тело от начала до конца и возвращается обратно.

Дальше программа продолжается с той строки, где была.

Как объявить функцию

Разберём по частям, как создаётся своя функция. Ничего сложного — всё уже знакомо из прошлых уроков.

Строение функции

ключевое слово
имя функции
параметры
def print_label():
print('ЦЕНТР УСПЕХ') print('Имя: ____') print('Курс: ____') print('Группа: _____') ← это тело функции

Четыре правила

1 Строка начинается со слова def (от англ. define — «определить»).
2 Дальше — имя функции. Мы придумываем его сами.
3 Затем — круглые скобки и двоеточие. В скобках может быть пусто или список параметров.
4 Тело функции пишется с отступом в 4 пробела, как в if или while.

Как назвать функцию

К имени функции предъявляются те же требования, что и к переменным: только латиница, цифры и _, не начинать с цифры, не использовать зарезервированные слова.

Но есть ещё хорошая привычка:

Приветствуетhello, greet
Что-то показываетshow_...
🎨 Стиль имён

Функции принято называть глаголами — ведь они что-то делают. И маленькими буквами, слова через подчёркивание: print_label, show_menu.

Полная программа

⚠️ Порядок важен

Функцию нужно объявить до того, как её вызовут. Python читает код сверху вниз: если строка с вызовом стоит раньше, чем объявление — будет ошибка NameError.

⏱ 23–31 минут · 🎁 Параметры

Параметры и аргументы

Учителя просят: чтобы этикетка печатала ещё и имя ученика. Каждый раз — разное. Как передать имя внутрь функции?

🤖
Задача усложнилась! На этикетке должно быть не просто «Имя: ____», а конкретное имя — например, «Имя: Александров Михаил». Но имена у всех разные. Как в одну функцию передать разные данные?

Ответ: через параметры. Это переменные, которые стоят в скобках при объявлении функции.

Параметр функции
Переменная, которая указывается в скобках при объявлении функции. Она получает значение в момент вызова.
def print_label(name): — здесь name это параметр.
Аргумент функции
Конкретное значение, которое передаётся в функцию в момент её вызова.
print_label('Александров Михаил') — здесь 'Александров Михаил' — это аргумент.
🧠 Как запомнить

Параметр — это «дырочка» в функции, переменная внутри. Она есть всегда, но пока пустая.

Аргумент — это то, что мы «вкладываем» в эту дырочку при вызове. Каждый раз может быть разное.

Пример: приветствие по имени

def hello(user_name): print('Здравствуйте, ' + user_name + '!') name = input('Введите имя: ') hello(name)
Что выведет программа
Введите имя: Павел
Здравствуйте, Павел!

Разбор по шагам

Объявление: def hello(user_name) — создали функцию с параметром user_name
Пользователь ввёл имя: 'Павел' — оно попало в переменную name
Вызов: hello(name) — передали аргумент 'Павел'
Внутри функции параметр user_name стал равен 'Павел'
Выполнилось print('Здравствуйте, ' + user_name + '!')

Возвращаемся к этикеткам

Обновим функцию: пусть она принимает имя и печатает его на этикетке.

def print_label(name): print('ЦЕНТР УСПЕХ') print('Имя:', name) print('Курс: английский язык') print('Печать листов контрольной работы') amount = int(input('Число учеников: ')) for i in range(amount): name = input('Имя ученика: ') print_label(name)
Что выведет программа
Печать листов контрольной работы

Имя ученика: Александров Михаил
ЦЕНТР УСПЕХ
Имя: Александров Михаил
Курс: английский язык
Имя ученика: Лисина Дарья
ЦЕНТР УСПЕХ
Имя: Лисина Дарья
Курс: английский язык
⚠️ Сколько параметров — столько аргументов

Если в объявлении функции указан один параметр, то при вызове нужно передать ровно один аргумент. Больше или меньше — ошибка TypeError.

Функция с несколькими параметрами

А если нужно передать и имя, и курс? Просто перечислим их через запятую:

def print_label(name, course): print('ЦЕНТР УСПЕХ') print('Имя:', name) print('Курс:', course) print_label('Аня', 'английский')
Что выведет
ЦЕНТР УСПЕХ
Имя: Аня
Курс: английский
🧠 Порядок важен

Первый параметр получает первый аргумент, второй — второй. Не путай их местами.

print_label('Аня', 'английский') — сначала имя, потом курс. Если поменять местами, всё сломается.

Функция внутри цикла — наша сила

Самое важное в функциях: их можно вызывать внутри других конструкций. Например, в цикле. Программа становится короче и понятнее.

🤖
Сравни, как выглядела задача «Печать этикеток» до функций и как — после. Разница заметна сразу!

Сравним два подхода

Без функции
amount = int(input('Число: '))

for i in range(amount):
    print('ЦЕНТР УСПЕХ')
    print('Имя: ____')
    print('Курс: ____')
    print('Группа: _____')

print('Готово!')
→
С функцией
def print_label():
    print('ЦЕНТР УСПЕХ')
    print('Имя: ____')
    print('Курс: ____')
    print('Группа: _____')

amount = int(input('Число: '))

for i in range(amount):
    print_label()

print('Готово!')

Кода стало не меньше — но зато код стал понятнее. А если этикетку нужно будет напечатать ещё где-то — мы просто вызовем print_label(), и всё.

А теперь — супер-сила

Одна функция — много применений. Посмотри, как одна и та же функция используется в двух разных программах.

# Объявляем один раз def print_label(name): print('ЦЕНТР УСПЕХ') print('Имя:', name) print('Курс: английский язык') # Используем в первой программе — печатаем наклейки print('Печать наклеек для тетрадей') amount = int(input('Сколько учеников? ')) for i in range(amount): name = input('Имя: ') print_label(name) # Используем во второй программе — печатаем бейджи print('Печать бейджей для конференции') amount = int(input('Сколько участников? ')) for i in range(amount): name = input('Имя участника: ') print_label(name)

Одно объявление — и два совершенно разных применения. Именно в этом главная сила функций.

🎯 Зачем это нужно

Учителя центра будут работать с одним и тем же кодом. Одна функция — и этикетки для тетрадей, и бейджи для мероприятий, и фирменные бланки для заданий.

Если завтра попросят поменять шапку на «ЦЕНТР УСПЕХА» — исправим в одном месте, и всё заработает.

Функция внутри условия

Функции можно вызывать и внутри условных конструкций. Например, бот из прошлого урока мог бы использовать функции для своих действий:

def tell_joke(): print('Первые пять дней после выходных — самые трудные!') def give_advice(): print('Учись понемногу каждый день.') action = input('1 — шутка, 2 — совет, off — выход: ') while action != 'off': if action == '1': tell_joke() elif action == '2': give_advice() else: print('Не знаю такого действия') action = input('1 — шутка, 2 — совет, off — выход: ')

Каждое действие — отдельная функция со своим именем. Программа стала чище и понятнее.
