⏱ 5–14 минут · 💬 Разговор

Первая версия бота

Начнём с самого простого: бот умеет отвечать на вопросы и завершает работу, когда пользователь вводит «off».

Нужны две конструкции сразу:

📖 Цикл while — чтобы бот ждал новых вопросов, пока не скажут «off».
🧠 if / elif / else — чтобы выбрать правильный ответ на каждый вопрос.

То есть один блок — if/elif/else — находится внутри цикла while. Это и есть первая вложенная конструкция.

Код бота

question = input('Спроси меня о чём-нибудь (off — завершить): ') while question != 'off': if question == 'Что ты умеешь?': print('Могу поговорить с тобой, если тебе грустно') elif question == 'Расскажи шутку': print('Первые пять дней после выходных — самые трудные!') else: print('Извини, не понимаю тебя') question = input('Спроси меня о чём-нибудь (off — завершить): ')

Разбор по шагам

1 Спрашиваем вопрос до цикла — чтобы было что проверять.
2 Пока не «off» — заходим внутрь цикла.
3 Внутри — if / elif / else: выбираем один из трёх ответов.
4 В конце тела цикла снова спрашиваем вопрос — чтобы на следующем шаге было что проверять.
🧠 Что происходит

Цикл повторяет весь блок if/elif/else, пока пользователь не введёт «off». На каждом шаге выполняется одна из трёх веток — в зависимости от вопроса.

Так одна программа умеет «вести диалог»: сколько бы раз пользователь ни спрашивал, бот каждый раз отвечает.

Первая версия бота работает. Но чтобы он был настоящим другом, ему нужно меню: «введи 1 — расскажу шутку, 2 — посоветую музыку».

🤖
Теперь мне нужно не просто отвечать на вопросы, а выполнять разные действия по номеру. И каждое действие — тоже программа: что-то спросить, что-то посчитать, что-то напечатать.

Что должен уметь бот-друг

1 Шутка. Просто печатает шутку.

⚠️ Главное правило

Чем глубже уровень, тем больше пробелов в начале строки. Отступ показывает Python, что команда лежит внутри другого блока.

Если отступ «съедет» — программа сломается. Легко запутаться, поэтому пиши код постепенно и проверяй каждый уровень.

🧠 Как это устроено

Внешний while держит бота «включённым» — пока не скажут «off».

Внутри — цепочка if / elif / else. Каждая ветка — отдельное действие: шутка, музыка, игра.

В ветке «музыка» — ещё одно условие (про настроение). В ветке «игра» — цикл на три попытки и внутри него — проверка «угадал или нет».

Каждый уровень решает свою задачу. Так получается вложенная конструкция.

Игра «Угадай число»

Разберём самую сложную часть бота отдельно: игру «Угадай число» с тремя попытками. Это цикл внутри условия внутри цикла.

🤖
Задача: я загадал число 7. Даю три попытки. Если ты угадаешь — кричу «Угадал!» и не заставляю тратить оставшиеся попытки. Если нет — даю следующую.

План игры

1 Три попытки. Значит, цикл for с range(3).
2 На каждой попытке спрашиваем число и сравниваем с загаданным.
3 Если угадал — break, чтобы выйти из цикла сразу.

Код игры

print('Я загадал число от 1 до 10. Угадаешь с трёх попыток!') for i in range(3): n = int(input('Твоя догадка: ')) if n == 7: print('Угадал! 🎉') break else: print('Не угадал, попробуй ещё')

Разбор вложенности

for i in range(3):              ← цикл на три попытки

    n = int(input('Твоя догадка: '))

    if n == 7:                  ← проверка угадал/нет
        print('Угадал! 🎉')
        break                    ← досрочный выход
    else:
        print('Не угадал, попробуй ещё')
🧠 Что делает break

break выходит из ближайшего цикла. Если игрок угадал на первой попытке — Python не станет проверять остальные две. Цикл немедленно прекращается.

Если игрок не угадал ни разу — цикл пройдёт все три попытки и завершится сам.

⚠️ Внимание на отступы

break стоит с дополнительным отступом — внутри if, который сам внутри for. Если поставить break на уровень for (без отступа внутрь if), программа сломается.
