Кондитерская «Сладкие истории»

Байт снова на связи. Ему поручили новый проект — на этот раз для кондитерской. Программа должна выбирать товар по предпочтениям покупателя.

🤖
Директор кондитерской объяснил задачу. Например, покупатель пишет, что любит конфеты. Программа должна сразу понять это и предложить леденцы. А если он любит что-то другое — предложить пирожные.

Пока — упрощённая задача. В программе всего два варианта рекомендации: леденцы или пирожные. Как решить, что выдать?

Блок-схема выбора

Программисты часто рисуют логику программы в виде схемы. Посмотри, как это выглядит:

Ввод предпочтения покупателем
↓
Предпочтение — конфеты?
Да
↓
Вывод: леденцы
Нет
↓
Вывод: пирожные
↓
Конец

В ромбике — вопрос. Программа отвечает на него «да» или «нет» и идёт по одной из двух дорожек. Это и есть выбор.

🤖
Получается, что мне нужно уметь задавать программе вопросы, на которые можно ответить только «да» или «нет». Например: «предпочтение — это конфеты?» Да или нет?
💭 Как задавать вопросы компьютеру

В программировании вопрос, на который можно ответить только «истина» или «ложь», называется условием.

Условие — это как предложение: «на улице идёт дождь». Оно может быть истинным или ложным. Именно так программа и принимает решения.

⏱ 7–15 минут · ✅ Логический тип

True и False — новый тип данных

Условие может быть только истинным или ложным. Для такого «двухвариантного» значения в Python есть специальный тип.

True «Истина». Условие выполняется.
False «Ложь». Условие не выполняется.
Логический тип данных
Это тип для программирования предложений, которые могут быть истинными или ложными. Обозначается bool.
Возможные значения: True и False. Пишутся с большой буквы.

Пример из жизни

У любого условия есть только два ответа. Сравни:

ПредложениеОтвет
Наличие больше проданногоTrue
Наличие меньше проданногоFalse
Возраст покупателя больше 18True или False
Слово «уют» есть в отзывеTrue или False

Как записать в переменную

checked = True
is_sent = False
print ( checked )
print ( is_sent )
Вывод программы

⚠️ Важно!

True и False пишутся с большой буквы. Если написать true или false — Python подумает, что это имя переменной, и выдаст ошибку.

Операторы сравнения

Чтобы получить True или False, нужно сравнить два значения. Для этого в Python есть специальные операторы.

🤖
Например, у меня есть число на складе — 150 кг конфет. И я хочу узнать, нужно ли заказывать ещё. Сравню наличие с минимумом — 50 кг. Как это записать?

Шесть операторов сравнения

ОператорСмысл
>больше
<меньше
==равно
!=не равно
<=меньше или равно
>=больше или равно
⚠️ Не путай = и ==

Один знак = — это присваивание: «положи значение в переменную».

Два знака == — это сравнение: «проверь, равны ли эти два значения». Результат — True или False.

Пример: склад конфет

Напишем программу, которая проверяет, нужно ли пополнять склад. Минимум — 50 кг.

# Спрашиваем остаток на складе amount_store = int(input('Наличие: ')) # Сравниваем с минимумом amount_min = 50 delivery = amount_store < amount_min print('Нужна доставка:', delivery)
Что выведет программа
Наличие: 50
Нужна доставка: False

Наличие: 49
Нужна доставка: True

Когда на складе 50 кг — заказывать не нужно (False). Когда 49 кг — уже нужно (True).

🧠 Как это работает

Оператор < сравнивает два числа и возвращает логическое значение: True или False.

Это значение можно сохранить в переменную или сразу напечатать.

Составные условия

Иногда одной проверки мало. Нужно, чтобы выполнялись сразу два условия — или хотя бы одно из двух.

🤖
Заказчик говорит: «Ошибка хранения возникает, когда склад почти пуст или когда склад переполнен». Как мне соединить два условия в одном?

Два логических оператора

ОператорИспользуется, когда нужно
andПотребовать выполнения двух условий одновременно
orПотребовать выполнения хотя бы одного из двух условий

Пример: склад конфет

Ошибка хранения — если на складе меньше 50 кг или больше 300 кг. Значит, используем or.

amount_store = int(input('Наличие: ')) error = amount_store < 50 or amount_store > 300 print('Ошибка хранения: ', error)
Что выведет программа
Наличие: 540
Ошибка хранения: True

Наличие: 275
Ошибка хранения: False

540 — больше 300, ошибка есть. 275 — в норме, ошибки нет.

Пример с and

А если нужно проверить, что склад в норме — то есть количество от 50 до 300? Тогда нужен and:

amount_store = int(input('Наличие: ')) ok = amount_store >= 50 and amount_store <= 300 print('Склад в норме:', ok)
🧠 Как Python считает составные условия

Сначала вычисляются значения простых условий — например, amount_store < 50. Потом Python смотрит на логический оператор (and или or) и объединяет результаты в одно значение.

⏱ 30–40 минут · 🧠 Условный оператор

Учим программу выбирать

Мы научились составлять условия. Теперь разберёмся, как заставить программу выполнять разные действия в зависимости от того, истинно условие или ложно.

Условный оператор
Это команда, выполняющая или не выполняющая действие в зависимости от значения логического выражения.
Если условие истинно — одно действие. Если ложно — другое (или ничего).

Две формы записи

Форма 1. Только if — действие выполняется, только если условие истинно.

if условие: действие_1 действие_2 действие_3

Если условие ложно — программа пропустит весь блок и пойдёт дальше.

Форма 2. if / else — два разных действия.

if условие: действие_1 else: действие_2
⚠️ Два важных правила

1. После условия ставится двоеточие :
2. Действия внутри блока пишутся с отступом в 4 пробела. Отступ показывает Python, что эти команды — часть условного оператора.

Задача: рекомендация по вкусу

Программа спрашивает любимый вкус покупателя. Если ванильный — предлагает чизкейк. Иначе — ореховый торт.

taste = input('Введите любимый вкус: ') taste = taste.lower() if taste == 'ванильный': print('Попробуйте наш фирменный чизкейк!') else: print('Попробуйте ореховый торт!')
Что выведет программа
Введите любимый вкус: Ванильный
Попробуйте наш фирменный чизкейк!

Введите любимый вкус: шоколадный
Попробуйте ореховый торт!
🧠 Разбор по шагам

1. Программа спрашивает вкус и сохраняет ответ в taste.
2. Метод .lower() приводит текст к нижнему регистру — чтобы «Ванильный» и «ванильный» считались одинаковыми.
3. Оператор if taste == 'ванильный' — проверяет условие.
4. Если True — печатает чизкейк. Если False — идёт в else и печатает ореховый торт.

Задача: покупка по карте

Ещё один пример. Программа проверяет, хватит ли денег на карте для покупки:

total = int(input('Сумма к оплате: ')) balance = int(input('Остаток на карте: ')) if total > balance: print('Недостаточно средств') else: print('Покупка одобрена')

01 Сравни числа 🌱

Спроси два числа и выведи результаты всех шести сравнений.

💡 Подсказка

Шесть команд print с операциями > < == != <= >=.

✅ Решение 
a = int(input("Первое: "))
b = int(input("Второе: "))
print(a > b)
print(a < b)
print(a == b)
print(a != b)
print(a <= b)
print(a >= b)
02 Проверка возраста 🌱

Спроси возраст. Если 18 или больше — выведи «Взрослый», иначе — «Ребёнок».

💡 Подсказка

Условие if age >= 18:, дальше else:. Не забудь отступ.

✅ Решение 
age = int(input("Возраст: "))
if age >= 18:
    print("Взрослый")
else:
    print("Ребёнок")
03 Рекомендация по вкусу 🌱🌱

Спроси любимый вкус. Если «ванильный» — предложи чизкейк, иначе — ореховый торт.

💡 Подсказка

Используй .lower(), чтобы не зависеть от регистра.

✅ Решение 
taste = input("Любимый вкус: ").lower()
if taste == "ванильный":
    print("Попробуйте чизкейк!")
else:
    print("Попробуйте ореховый торт!")
04 Оплата по карте 🌱🌱

Спроси сумму покупки и остаток на карте. Если денег не хватает — «Недостаточно средств», иначе — «Покупка одобрена».

💡 Подсказка

Условие: total > balance.

✅ Решение 
total = int(input("Сумма к оплате: "))
balance = int(input("Остаток на карте: "))
if total > balance:
    print("Недостаточно средств")
else:
    print("Покупка одобрена")
05 Чётное или нечётное 🌱🌱

Спроси число. Если оно делится на 2 без остатка — «Чётное», иначе — «Нечётное».

💡 Подсказка

Остаток от деления — оператор %. Проверка: n % 2 == 0.

✅ Решение 
n = int(input("Число: "))
if n % 2 == 0:
    print("Чётное")
else:
    print("Нечётное")
06 Склад в норме 🌱🌱🌱

Спроси количество конфет на складе. Выведи True, если их от 50 до 300 включительно. Иначе False.

💡 Подсказка

Используй and: 50 <= n <= 300 или n >= 50 and n <= 300.

✅ Решение 
n = int(input("Наличие: "))
ok = n >= 50 and n <= 300
print(ok)
07 Ошибка хранения 🌱🌱🌱

Спроси количество. Выведи True, если склад почти пуст (меньше 50) или переполнен (больше 300). Иначе False.

💡 Подсказка

Используй or: n < 50 or n > 300.

✅ Решение 
n = int(input("Наличие: "))
error = n < 50 or n > 300
print(error)
08 Найди и исправь 🌱🌱🌱

В стартовом коде три ошибки: нет двоеточия, нет отступа, неправильный оператор сравнения. Исправь.

💡 Подсказка

Проверь: двоеточие после if? Отступ у print в 4 пробела? == для сравнения?

✅ Решение 
age = int(input("Возраст: "))
if age >= 18:
    print("Доступ разрешён")
else:
    print("Доступ запрещён")
