⏱ 6–16 минут · 🧠 Первые понятия

Алгоритм, язык, программа

Три слова, без которых не обходится ни один программист. Разберём их по очереди — на примерах, без заумных слов.

🤖
Смотри. Представь, что я — твой помощник. Но я совсем не умею догадываться. Если ты скажешь «нарисуй домик», я не пойму. А если объяснишь по шагам — нарисую.

Список шагов, по которым что-то делается, называется алгоритмом.

Алгоритм
Это последовательность действий для достижения цели.
Пример: «Взять лист. Взять карандаш. Нарисовать квадрат. Раскрасить». Это алгоритм рисования квадрата.

Собери алгоритм

Расставь шаги в правильном порядке — чтобы получился алгоритм «Съесть печенье».

Что делает алгоритм хорошим

Три простых правила. Запомни их — они пригодятся.

1 Полный. Если шаг пропущен — цель не достигнута. Я не догадаюсь, что ты хотел сказать.
2 По порядку. Сначала «открыть коробку», потом «взять печенье». Не наоборот.
3 Без догадок. «Иди туда» — непонятно. «Иди к двери» — понятно. У каждого шага одно значение.
⚠️ Пример плохого алгоритма

«Сложи всё. Напечатай результат. Вычти что-то».

Что сложить? Что напечатать? Что вычесть? Непонятно. Компьютер такой алгоритм выполнить не сможет — он не умеет угадывать.

Теперь — язык

Алгоритм можно записать словами. Но компьютер человеческий язык не понимает. Ему нужен свой — специальный.

Язык программирования
Это язык для общения с компьютером. Он состоит из команд. У каждой команды только одно значение.
В Python команда print всегда означает «напечатай». Не «подумай», не «подожди» — только «напечатай».

И наконец — программа

Программа
Это алгоритм, записанный на языке программирования.
Ты придумал алгоритм — список шагов. Записал его командами Python — получилась программа. Компьютер её читает и выполняет.
🔗 Как связаны три слова

Алгоритм — план на словах.
Язык программирования — способ записать план.
Программа — готовый текст, который компьютер выполнит.

⏱ 22–32 минут · 📺 Первая команда

Знакомься: print()

Первое, что должен уметь программист, — вывести что-то на экран. Для этого в Python есть готовая функция.

Функция
Это готовая команда с именем. Ты её вызываешь — она делает свою работу. Данные, которые ты ей передаёшь, называются аргументами.
Пример: у тебя есть готовая функция «открыть дверь». Ты говоришь ей «открой эту дверь» — и она открывает. Твоя фраза — аргумент.

Как выглядит print()

print ( "Привет!" )

Разберём по частям:

1 print — имя функции. «Печатать».
2 ( ) — скобки. Внутрь кладём то, что печатаем.
3 "Привет!" — аргумент. Текст в кавычках.

Если запустить эту программу, на экране появится:

Вывод программы
Привет!
🤖
Запомни главное: что положишь в скобки — то и напечатается. Текст всегда в кавычках. Числа — без кавычек. Попробуй!

Что напечатает print()?

Введи любой текст — увидишь, что именно выведет Python.

Несколько значений сразу

В print() можно передать сразу несколько аргументов — через запятую. Python напечатает их через пробел.

print ( "Мне" , 12 , "лет" )

Мне 12 лет

⚠️ Обрати внимание

Запятая между аргументами обязательна. Если её пропустить, Python не поймёт: print("Мне" 12 "лет") — ошибка.

⏱ 32–38 минут · ➕ print() считает

print() умеет считать

В скобках print() можно писать не только готовые числа, но и примеры. Python сначала посчитает, потом напечатает результат.

print ( 2 + 3 ) ← напечатает 5

Четыре простые операции

Что написалиЧто получилось
print(2 + 7)9
print(10 - 4)6
print(3 * 4)12
print(8 / 2)4.0
🔍 Почему 4.0, а не 4?

Оператор / (деление) в Python всегда даёт дробное число — даже если получается целое. Поэтому 8 / 2 → 4.0.

А если результат уже дробный, всё остаётся как есть: 7 / 2 → 3.5.

Ещё три операции

Что написалиЧто получилось
print(14 // 3)4 (целая часть)
print(14 % 3)2 (остаток)
print(3 ** 3)27 (3 × 3 × 3)

// — это «деление без остатка». % — «остаток от деления». ** — «возведение в степень».

Порядок операций

Python считает как в математике: сначала умножение и деление, потом сложение и вычитание. Скобки меняют порядок.

Что написалиЧто получилось
print(1 + 1 * 7)8
print((1 + 1) * 7)14
🤖
Если сомневаешься — ставь скобки. Лишние скобки не помешают, а вот пропущенные могут запутать Python. Держи порядок под контролем!

Игра: что напечатает Python?

Посмотри на пример и напиши ответ. Если получилось дробное число — используй точку: 3.5.

Что выведет:
print(2 + 3)
Счёт: 0 из 0
⏱ 38–45 минут · 🏁 Правила и итог

Три правила оформления

Чтобы Python понял твою программу, следуй простым правилам.

1 Начало строки. Каждая команда начинается с самого начала строки, без отступов.
2 Порядок. Команды выполняются сверху вниз, одна за другой.
3 Регистр. Пиши print маленькими буквами. Print и PRINT — ошибка.
🚨 Python не угадывает

print — работает.
Print — ошибка.
принт — ошибка.
print с русскими буквами «р», «и» — тоже ошибка.

Даже лишний пробел в начале строки может сломать программу. Поэтому будь внимателен.

Два аргумента в кавычках: "Привет" и "хакеры". Python сам поставит между ними пробел.

print("Мой возраст:", 12)
04 Итого к оплате 🌱🌱

Посчитай прямо в print: 150 * 3 и выведи Итого: 450.

✅ Решение 
print("Итого:", 150 * 3)

Выведи результаты пяти операций над 14 и 4: +, −, *, /, %.

print(14 - 4)

print(14 % 4)
06 Порядок операций 🌱🌱

Выведи два примера и сравни результат: 1 + 1 * 7 и (1 + 1) * 7.

💡 Подсказка

В первом случае Python сначала умножит, потом сложит. Во втором — сначала скобки.

✅ Решение 
print(1 + 1 * 7)
print((1 + 1) * 7)
07 Степени 🌱🌱🌱

Выведи 3 ** 3 и 2 ** 10 с подписями.

💡 Подсказка

Оператор степени — **. Сначала текст в кавычках, потом выражение через запятую.

✅ Решение 
print("3 в 3-й:", 3 ** 3)
print("2 в 10-й:", 2 ** 10)
