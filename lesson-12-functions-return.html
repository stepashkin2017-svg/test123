🤖
Учитель Ольга Сергеевна попросила: пусть программа спрашивает у неё имя ученика и оценки — а потом посчитает средний балл. Я написал функцию average_grade(), но получилось не так, как я хотел.

Вот что сделал Байт:

def average_grade(name): grade = input('Оценка (off — стоп): ') summa = 0 total = 0 while grade != 'off': summa += int(grade) total += 1 grade = input('Оценка (off — стоп): ') print(name, '— средний балл —', summa / total) name = input('Имя ученика: ') average_grade(name)

Функция работает — средний балл печатается. Но учительница хочет использовать этот балл дальше.

💭 Что нужно

Учительнице нужен результат функции — число. Его нужно сохранить в переменную и потом использовать в основной программе.

А сейчас функция просто печатает. Напечатанное число дальше использовать нельзя — оно «вылетает» на экран и исчезает.

⏱ 6–14 минут · ❌ Ловушка

Попробуем вытащить значение — получим ошибку

Естественная мысль: а что если вынести переменную из функции и напечатать её снаружи? Проверим.

Байт попробовал так:

def average_grade(name): grade = input('Оценка (off — стоп): ') summa = 0 total = 0 while grade != 'off': summa += int(grade) total += 1 grade = input('Оценка (off — стоп): ') average = summa / total name = input('Имя ученика: ') average_grade(name) print(average) # хотим напечатать снаружи

Что произойдёт? Программа сломается:

Ошибка!
Имя ученика: Иван
Оценка (off — стоп): 4
Оценка (off — стоп): 5
Оценка (off — стоп): off
NameError: name 'average' is not defined
🚨 Почему так

Переменная average была создана внутри функции. Python считает функцию отдельным миром: переменные, созданные в функции, видны только ей.

Из основной программы их не видно. Вот почему интерпретатор жалуется: name 'average' is not defined.

Две комнаты

Представь, что функция — это отдельная комната. В каждой комнате свои вещи. Из главной комнаты ты не видишь, что лежит в комнате функции.

Основная программа
📦 name = 'Иван'
❓ average = ??? — нет!
Функция average_grade
📦 grade
📦 summa
📦 total
📦 average = 4.5
Локальная переменная
Переменная, созданная внутри функции. Она «принадлежит» функции и видна только внутри неё. Из основной программы к ней обратиться нельзя.
summa, total, average — всё это локальные переменные функции.
⚠️ Почему так сделано

Это защита. Если бы функции могли менять любые переменные программы, было бы очень сложно искать ошибки. Внутри функции — свой мир, и это хорошо.

Но тогда как передать результат наружу? Для этого есть специальный оператор.

⏱ 14–22 минут · ↩️ return

Оператор return — функция отдаёт результат

Чтобы вернуть значение из функции в основную программу, используют слово return — «вернуть».

Оператор return
Возвращает из функции значение в то место, где её вызвали. После return функция сразу завершается — команды после него не выполняются.
return average — «верни значение переменной average».

Как выглядит в коде

def average_grade(name): grade = input('Оценка (off — стоп): ') summa = 0 total = 0 while grade != 'off': summa += int(grade) total += 1 grade = input('Оценка (off — стоп): ') average = summa / total return average # Используем результат снаружи name = input('Имя ученика: ') avg = average_grade(name) print(name, '— средний балл —', avg)
Что выведет программа
Имя ученика: Иван
Оценка (off — стоп): 4
Оценка (off — стоп): 5
Оценка (off — стоп): off
Иван — средний балл — 4.5

Как работает return

Внутри функции
average = 4.5
↩️ return
В основной программе
avg = 4.5
1 return пишется внутри функции.
2 После него указывают значение, которое нужно вернуть.
3 Функция сразу завершается — команды после return уже не выполняются.
4 Возвращённое значение можно присвоить переменной или сразу использовать.
🧠 Два вида функций

Без return — «что-то сделала, напечатала, забыла». Результат снаружи недоступен.

С return — «что-то посчитала и отдала результат». Снаружи можно им пользоваться как удобно.

Функция может вернуть что угодно

Функция возвращает не только числа. Можно вернуть строку, значение True/False и многое другое.

returnЧто вернёт
return averageчисло
return 'отлично'строку
return x > 5True или False

Локальные переменные — подробнее

Разберёмся, почему переменные внутри функции не видны снаружи. И что можно, а что нельзя.

🤖
Я понял: функция — это как отдельная комната с собственными вещами. Если снаружи попросить вещь из комнаты — Python скажет «не знаю такую».

Что работает и что нет

Снаружи, в основной программе
✅ name = 'Иван' — своя переменная
✅ result = average_grade(name) — вызываем
❌ print(summa) — NameError
❌ print(average) — NameError
Внутри функции average_grade
✅ summa, total, average
✅ name — параметр, доступен
❌ result — переменная снаружи
↩️ return average — вот как наружу
🧠 Правило

Всё, что создано внутри функции, живёт только внутри неё. Снаружи её можно «увидеть» только через return.

Параметры функции тоже локальные — они видны только внутри неё.

Простой пример

Разберём на маленькой функции — просто чтобы увидеть разницу.

def double(x): result = x * 2 return result n = 5 twice = double(n) print(twice) # А это уже не сработает: # print(result) → NameError # print(x) → NameError
Что выведет
10

Внутри функции result и x есть. Снаружи их не существует. Работает только то, что функция отдала через return.

Возвращаемся к среднему баллу

И теперь — то, что просила учительница. Средний балл хранится в переменной avg и его можно использовать для проверки допуска к олимпиаде:

name = input('Имя ученика: ') avg = average_grade(name) if avg >= 4.5: print(name, 'допущен к олимпиаде!') else: print(name, 'нужно ещё подтянуть оценки')
Что выведет программа
Имя ученика: Иван
Оценка (off — стоп): 5
Оценка (off — стоп): 5
Оценка (off — стоп): off
Иван допущен к олимпиаде!
🎯 Что получилось

Функция average_grade() посчитала средний балл и вернула его. Основная программа использовала его для проверки.

Именно так и должны работать функции: одна отвечает за подсчёт, другая — за решение.

⏱ 31–40 минут · 🏆 Олимпиада

Программа про олимпиаду

Закрепим на большой задаче. Центр «Успех» проводил олимпиаду по географии, и нужна программа, которая по баллам определяет награду ученика.

Условия олимпиады

🥇 200 баллов и больше — диплом I степени + сертификат в книжный магазин.
🥈 От 100 до 199 — диплом II степени.
🥉 От 50 до 99 — диплом III степени.
📜 Меньше 50 — благодарственное письмо.

Что должна сделать программа

Функция get_result(score) принимает балл и возвращает название награды. Основная программа печатает результат и, если это диплом I степени, добавляет информацию о подарке.

def get_result(score): if score >= 200: result = 'диплом I степени' elif score >= 100: result = 'диплом II степени' elif score >= 50: result = 'диплом III степени' else: result = 'благодарственное письмо' return result # Основная программа name = input('Имя ученика: ') score = int(input('Набранный балл: ')) result = get_result(score) print(name, '—', result) if result == 'диплом I степени': print('Подарок — сертификат в книжный магазин')
Что выведет программа
Имя ученика: Артур
Набранный балл: 211
Артур — диплом I степени
Подарок — сертификат в книжный магазин

Разбор по шагам

Внутри функции get_result: получили score = 211
Проверили: 211 >= 200? Да. Значит result = 'диплом I степени'.
return result — вернули строку в основную программу.
В основной программе получили: result = 'диплом I степени'
Напечатали: «Артур — диплом I степени»
Проверили: result == 'диплом I степени'? Да. Печатаем подарок.
🧠 Что мы сделали

Функция отвечает за выбор награды по баллам. Это отдельная задача.

Основная программа собирает данные, вызывает функцию и решает, что делать дальше — например, добавить подарок.

Каждая часть делает своё дело. Программа получается чистой и понятной.

💡 Порядок проверок

В функции get_result проверки идут от большего к меньшему. Так короче: если балл уже больше 200, нет смысла проверять остальные ветки.

02 Сумма двух чисел 🌱

03 Максимум из двух 🌱🌱

Функция get_max(a, b) возвращает большее из двух чисел.

💡 Подсказка

Внутри — if / else с двумя return.

✅ Решение 
def get_max(a, b):
    if a >= b:
        return a
    else:
        return b

print(get_max(3, 7))
print(get_max(10, 4))

05 Средний балл 🌱🌱🌱

Функция average(a, b, c) возвращает среднее арифметическое трёх оценок.

07 Функция в условии 🌱🌱🌱

Функция is_even(n) возвращает True, если число чётное. Спроси число и напечатай «чётное» или «нечётное» через функцию.

💡 Подсказка

Возврат: return n % 2 == 0. Снаружи — if is_even(x):.

def is_even(n):

    print("Нечётное")
08 Найди и исправь 🌱🌱🌱

Программа пытается напечатать переменную result из функции, но падает с NameError. Исправь через return.

💡 Подсказка

Добавь return в функцию и сохрани результат в переменную снаружи.

✅ Решение 
def calculate(a, b):
    result = a * b
    return result

x = calculate(6, 7)
print(x)
