⏱ 0–7 минут · 🎁 Вложенные конструкции

Одна команда внутри другой

Байт снова разбирал код турфирмы. И заметил: одну и ту же программу можно записать по-разному.

🤖
Смотри, что я нашёл! Вот так программу писал стажёр — в три строки. А вот так её можно записать короче — в одну. Работает одинаково!
Длинно — 3 строки
answer = input('Возраст: ')
age = int(answer)
print(age + 10)
→
Коротко — 2 строки
age = int(input('Возраст: '))
print(age + 10)

В первой программе мы сначала спрашивали возраст и сохраняли в переменную, а потом отдельно превращали её в число. Во второй — сделали обе операции сразу: одну команду поставили внутрь другой.

Вложенная конструкция
Это когда результат одной команды сразу передаётся в другую. Одна функция стоит внутри скобок другой функции.
int(input('Возраст: ')) — сначала работает input(), потом его результат идёт в int().

Как это выглядит схематично

Внешняя функция
Внутренняя функция input('Возраст: ')
int( ... )

Порядок работы такой: Python сначала выполняет внутреннюю функцию, потом её результат передаёт внешней.

🧠 Принцип матрёшки

Представь матрёшку. Внутри большой куклы — кукла поменьше. Чтобы достать маленькую, надо сначала открыть большую. Так же и с функциями: чтобы понять результат всей конструкции, смотрим изнутри наружу.

1 Внутренняя функция работает первой.
2 Её результат идёт во внешнюю функцию.
3 Внешняя функция работает второй.
🤖
Получается, что я как будто составляю команды из кусочков, как конструктор. И это работает с любыми функциями!
⏱ 7–16 минут · 🎤 Главная связка

int(input()) — комбо, которое пригодится всегда

Самая частая вложенная конструкция в Python. Её нужно знать наизусть.

🤖
Помнишь проблему с input()? Он возвращает строку, а не число. А если сразу обернуть его в int() — получим число. И всё это в одной строке!
age = int( input( 'Сколько тебе лет? ' ) )

Разберём по шагам

1 input('Сколько тебе лет? ') — Python спрашивает и получает строку, например '12'.
2 int(...) — превращает '12' в число 12.
3 Знак = — кладёт результат в переменную age.
Диалог с программой
Сколько тебе лет? 12
(внутри переменной age теперь число 12)

Другие полезные вложенные связки

КонструкцияЧто делает
int(input()) Спрашивает число и сразу превращает в int
float(input()) Спрашивает число и превращает в float
input().lower() Спрашивает текст и сразу приводит к нижнему регистру
len(input()) Спрашивает текст и сразу считает его длину
⚠️ Обрати внимание на порядок

int(input()) — работает. Сначала спрашиваем — потом превращаем.

input(int()) — не работает. Здесь Python попытается превратить в число пустые скобки int(), и получит ошибку.

Соединяем уже знакомые функции

Все функции из прошлых уроков можно вкладывать друг в друга. Разберём три полезных примера.

Пример 1. Сразу считаем длину введённого текста

length = len( input( 'Введите отзыв: ' ) )
print ( 'Длина отзыва:' , length )

Программа спрашивает отзыв и сразу считает его длину. Экономим одну строку кода — не нужно сохранять сам отзыв в переменную.

Пример 2. Ищем слово без учёта регистра

feedback = input( 'Отзыв: ' ) . lower ()

Здесь input() возвращает текст, а .lower() сразу приводит его к нижнему регистру. Запись читается как «спроси и приведи к нижнему регистру».

Пример 3. Комбинируем три функции сразу

pos = input( 'Отзыв: ' ) . lower () . find ( 'уют' )

Читаем слева направо:

1 input('Отзыв: ') — спрашивает текст.
2 .lower() — приводит его к нижнему регистру.
3 .find('уют') — ищет слово и возвращает номер.
🧠 Два вида вложенности

Функция внутри функции (int(input())) — читаем изнутри наружу.

Метод за методом (input().lower().find()) — читаем слева направо. Сначала работает то, что слева, потом то, что справа.

Сравнение двух стилей

Длинно
feedback = input('Отзыв: ')
feedback = feedback.lower()
pos = feedback.find('уют')
print(pos)
→
Коротко
pos = input('Отзыв: ').lower().find('уют')
print(pos)

Оба варианта работают. Первый — понятнее новичку. Второй — короче и читается «в одну строку».

Как читать длинные вложенные конструкции

Чем длиннее вложенность, тем важнее уметь её «расплетать». Разберём алгоритм.

🤖
Когда я впервые увидел строку из трёх-четырёх функций подряд, я испугался. А потом понял: если читать по шагам и заменять каждую функцию её результатом — всё становится просто.

Пример: разбираем по шагам

result = len ( input ( 'Отзыв: ' ) . lower () )

Что произойдёт, если пользователь введёт «Отличное место»?

1 Работает input('Отзыв: ') → возвращает 'Отличное место'.
2 Срабатывает .lower() → получаем 'отличное место'.
3 Работает len(...) → считает 14 символов.
4 Результат 14 попадает в переменную result.
🧠 Алгоритм расплетания

1. Найди самую внутреннюю функцию — она работает первой.
2. Замени её на её результат.
3. Повторяй, пока не останется одно значение.

Так можно разобрать любую вложенную конструкцию.

Ещё пример

n = int ( input ( 'Число: ' ) ) + 5

Если пользователь введёт 10:

1input() → '10' (строка)
2int(...) → 10 (число)
310 + 5 → 15
4В переменной n теперь 15
Вывод программы
Число: 10
(в переменной n теперь 15)

Когда вложенность помогает, а когда мешает

Вложенность — мощный инструмент. Но если увлечься, код превратится в непонятную «матрёшку». Разберём, где граница.

💡 Простое правило

Если конструкцию легко прочитать за 3 секунды — оставь короткой. Если нужно напрягаться и считать скобки — разбей на несколько строк.

Хорошо ✅

age = int ( input ( 'Возраст: ' ) )

Две функции, читается сразу: «спроси и преврати в число».

Тоже хорошо ✅

text = input ( 'Отзыв: ' ) . lower ()

Цепочка из двух действий: «спроси и приведи к нижнему регистру».

Плохо ❌

x = len ( input ( 'Текст: ' ) . lower () . strip () . replace ( ' ' , '' ) )

Слишком много всего в одной строке. Понять, что происходит, трудно. Лучше разбить:

text = input ( 'Текст: ' )
text = text . lower ()
text = text . strip ()
x = len ( text . replace ( ' ' , '' ) )

Так понятно, что происходит на каждом шаге.

✅ До 2–3 функций в одной строке — нормально.
⚠️ 4–5 функций — уже стоит подумать, читается ли.
❌ Больше 5 — точно разбивать на несколько строк.
