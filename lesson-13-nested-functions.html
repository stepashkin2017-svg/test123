⏱ 0–6 минут · 💭 Задача усложняется

Скидка на абонемент в планетарий

Директор центра «Успех» остался доволен первой частью автоматизации. Теперь присылает новый блок задач — и они явно сложнее.

🤖
Задача: ученикам с высоким средним баллом даётся скидка на абонемент в планетарий. Программа спрашивает оценки и считает средний балл. Если он больше или равен 4.7 — скидка 15%, иначе — 0%.
Что должна вывести программа
Оценка (0 — завершить): 4
Оценка (0 — завершить): 5
Оценка (0 — завершить): 5
Оценка (0 — завершить): 5
Оценка (0 — завершить): 0
Скидка на абонемент (%): 15

Байт уже собрался писать код — но тут подумал.

🤖
Стоп. А ведь подсчёт среднего балла наверняка понадобится ещё много раз: допуск к олимпиаде, отбор на факультативы, скидка на поездки. Если я сейчас напишу всё одной большой функцией — завтра придётся копировать этот код снова и снова.
💭 Идея

Разделим задачу на две части:

1. Посчитать средний балл — отдельная функция average_grade().
2. Решить про скидку — отдельная функция set_discount(). Внутри неё будем вызывать первую.

Каждая функция будет делать одно своё дело.

⏱ 6–14 минут · 🧩 Сначала — как плохо

Одна большая функция

Первое, что приходит в голову — написать одну функцию, которая делает всё. Посмотрим, как она выглядит.

def average_grade(): grade = int(input('Оценка (0 — завершить): ')) total = 0 average = 0 while grade != 0: average += grade total += 1 grade = int(input('Оценка (0 — завершить): ')) average /= total if average >= 4.7: return 15 else: return 0 print('Скидка на абонемент (%):', average_grade())

Работает? Да. Но обрати внимание: функция называется average_grade — «средний балл». А возвращает она… скидку. Это сбивает с толку.

🚨 Что не так

1. Название не соответствует действию. Функция называется «средний балл», а внутри считает скидку.

2. Средний балл «зашит» внутри. Если завтра он понадобится для другой задачи (олимпиады, факультатива), придётся копировать весь код.

3. Изменение правила скидки требует правки функции, которая вообще-то «про средний балл».

🤖
Кажется, я понял принцип. Одна функция — одно назначение. Пусть average_grade() считает только средний балл. А про скидку позаботится отдельная функция.
Правило: одна функция — одно назначение
Вместо одной громоздкой функции лучше сделать несколько маленьких. Каждая делает одну понятную вещь.
average_grade() — считает средний балл.
set_discount() — считает скидку.
Каждая функция делает только своё дело.

⏱ 14–24 минут · 🔗 Две функции

Разбиваем на две функции

Теперь каждая функция — про своё. А вместе они делают всю работу. Одна вызывает другую.

Вложенный вызов функции
Это когда внутри одной функции вызывается другая. То же правило вложенности, что мы видели у условий и циклов, работает и для функций.
set_discount() вызывает average_grade(), чтобы получить средний балл.

Новый код

def average_grade(): grade = int(input('Оценка (0 — завершить): ')) total = 0 average = 0 while grade != 0: average += grade total += 1 grade = int(input('Оценка (0 — завершить): ')) average /= total return average def set_discount(): avg = average_grade() # ← вызов первой функции if avg >= 4.7: return 15 else: return 0 print('Скидка на абонемент (%):', set_discount())
Что выведет программа
Оценка (0 — завершить): 4
Оценка (0 — завершить): 5
Оценка (0 — завершить): 5
Оценка (0 — завершить): 5
Оценка (0 — завершить): 0
Скидка на абонемент (%): 15

Как это устроено

Основная программа
set_discount()
↓
Функция set_discount
avg = average_grade() если avg >= 4.7 → return 15 иначе → return 0
↓
Функция average_grade
спрашивает оценки считает среднее return average
🧠 Что произошло

1. Основная программа вызывает set_discount().
2. Та вызывает average_grade() и получает средний балл.
3. Сравнивает балл с 4.7 и решает про скидку.
4. Возвращает скидку в основную программу.

Три уровня — как матрёшка из уроков 6 и 10.

Смотрим на порядок вызова

Программа запускается и доходит до set_discount()
Заходим внутрь set_discount. Встречаем average_grade().
Прыгаем в average_grade. Спрашиваем оценки, считаем среднее.
return average — средний балл возвращается в set_discount.
set_discount сравнивает балл с 4.7 и решает про скидку.
return 15 — скидка возвращается в основную программу.
print печатает результат.
💡 Что мы получили

Теперь average_grade() можно вызывать в любой другой программе — для олимпиады, для факультатива, где угодно. Это отдельная, полезная функция.

А set_discount() знает только про скидку и просто использует готовый результат.

Скидка на поездку в театр

Директор присылает ещё одну задачу — похожую, но с другим правилом. Убедимся, что структура «двух функций» работает и здесь.

🤖
Каждый год центр организует поездку в театр. Ученик может получить скидку на стоимость — в зависимости от того, сколько у него пятёрок за итоговые тесты: от 1 до 3 — 3%, от 4 до 5 — 5%, больше 5 — 10%.

План

1 amount_five() — спрашивает оценки и считает, сколько среди них пятёрок.
2 set_discount() — вызывает первую и по числу пятёрок решает, какая скидка.
3 Основная программа вызывает set_discount() и печатает результат.
def amount_five(): grade = int(input('Оценка (0 — завершить): ')) five = 0 while grade != 0: if grade == 5: five += 1 grade = int(input('Оценка (0 — завершить): ')) return five def set_discount(): n = amount_five() if n >= 1 and n <= 3: return 3 elif n >= 4 and n <= 5: return 5 elif n > 5: return 10 else: return 0 print('Скидка на поездку (%):', set_discount())
Что выведет программа
Оценка (0 — завершить): 5
Оценка (0 — завершить): 5
Оценка (0 — завершить): 4
Оценка (0 — завершить): 5
Оценка (0 — завершить): 5
Оценка (0 — завершить): 0
Скидка на поездку (%): 5
🧠 Структура та же

Первая функция — собирает данные и считает нужное число (в нашем случае — количество пятёрок).

Вторая функция — использует это число для принятия решения по правилам.

Такая структура подходит почти для любой задачи, где «сначала считаем, потом решаем».

Одна схема — много задач

ЗадачаЧто считаемЧто решаем
Планетарий Средний балл Скидка 15% или 0%
Театр Количество пятёрок 3% / 5% / 10% / 0%
Олимпиада Балл участника Диплом I / II / III / письмо
💡 Зачем это нужно

Функцию подсчёта можно переиспользовать в разных программах. А правила решения часто меняются — поэтому их удобно держать в отдельной функции.

⏱ 32–40 минут · 📊 Задача про ИМТ

Индекс массы тела

Ещё одна задача от центра — уже не про оценки, а про здоровье учителей. Здесь тоже удобно разделить работу на две функции.

🤖
Центр использует индекс массы тела для оценки рисков здоровья учителей. Формула: вес / (рост × рост). Программа спрашивает вес и рост, считает ИМТ и говорит, в норме ли вес.

Правила оценки

ИМТЧто значит
до 18.5 включительнонедостаточный вес
от 18.5 до 25 включительновес в норме
больше 25избыточный вес

План

1 calc_bmi() — считает ИМТ по весу и росту и возвращает число.
2 check_bmi() — вызывает первую функцию, сравнивает результат с границами и печатает вердикт.
def calc_bmi(weight, height): # weight в кг, height в метрах index = weight / (height * height) return index def check_bmi(weight, height): index = calc_bmi(weight, height) if index <= 18.5: print('Ваш ИМТ:', index, '— Недостаточный вес!') elif index <= 25: print('Ваш ИМТ:', index, '— Вес в норме!') else: print('Ваш ИМТ:', index, '— Избыточный вес') weight = float(input('Введите вес (кг): ')) height = float(input('Введите рост (м): ')) check_bmi(weight, height)
Что выведет программа
Введите вес (кг): 50
Введите рост (м): 1.60
Ваш ИМТ: 19.53125 — Вес в норме!
🧠 Разбор

calc_bmi() — «посчитать индекс по формуле». Знает только про формулу, ничего больше.

check_bmi() — «сравнить с границами и сказать вердикт». Не знает, как формула устроена — просто получает от первой функции число и сравнивает.

Так каждая функция делает одно своё дело.

💡 Про float()

Вес и рост могут быть дробными — например, 50.5 кг или 1.72 м. Поэтому используем float(), а не int(). Он превращает строку в дробное число.

Как функции вызывают друг друга

Основная программа
weight = ... height = ... check_bmi(weight, height)
↓
Функция check_bmi
index = calc_bmi(weight, height) если index ≤ 18.5 → «недостаточный вес» иначе если index ≤ 25 → «вес в норме» иначе → «избыточный вес»
↓
Функция calc_bmi
index = weight / (height * height) return index
🚨 Классическая ошибка в формуле

Можно случайно написать weight / height * height — без скобок. Тогда сначала выполнится деление, и результат получится совсем другой.

Правильно: weight / (height * height) — знаменатель обязательно в скобках.

Как работать. В каждой задаче — две функции: одна считает, другая решает. Вторая вызывает первую внутри себя.
01 Двойной вызов 🌱

Создай one() возвращает 10, two() возвращает one() * 2. Вызови two() и напечатай результат.

💡 Подсказка

Внутри второй функции просто вызывай первую.

✅ Решение 
def one():
    return 10

def two():
    return one() * 2

print(two())
02 Средний балл → скидка 🌱🌱

average() возвращает среднее трёх оценок. discount() вызывает её: если балл ≥ 4.5 — 10%, иначе — 0.

💡 Подсказка

Сначала объяви average(), потом discount(), внутри которой вызывай первую.

✅ Решение 
def average(a, b, c):
    return (a + b + c) / 3

def discount(a, b, c):
    avg = average(a, b, c)
    if avg >= 4.5:
        return 10
    return 0

print(discount(5, 5, 4))
03 Число пятёрок 🌱🌱

count_five(a, b, c) возвращает количество пятёрок среди трёх оценок. prize() вызывает её и возвращает строку: «диплом» при двух и больше, иначе — «без награды».

💡 Подсказка

count_five использует if внутри для каждой оценки.

✅ Решение 
def count_five(a, b, c):
    n = 0
    if a == 5: n += 1
    if b == 5: n += 1
    if c == 5: n += 1
    return n

def prize(a, b, c):
    n = count_five(a, b, c)
    if n >= 2:
        return "диплом"
    return "без награды"

print(prize(5, 5, 3))
04 ИМТ 🌱🌱🌱

calc_bmi(w, h) возвращает ИМТ. verdict(w, h) вызывает её и возвращает «норма» (18.5–25), «мало» или «много».

💡 Подсказка

Формула: w / (h * h). Проверки — по границам 18.5 и 25.

✅ Решение 
def calc_bmi(w, h):
    return w / (h * h)

def verdict(w, h):
    index = calc_bmi(w, h)
    if index <= 18.5:
        return "мало"
    elif index <= 25:
        return "норма"
    else:
        return "много"

print(verdict(50, 1.60))
05 Кафе 🌱🌱🌱

total(price, count) возвращает сумму покупки. with_tip(price, count) вызывает её и добавляет 10% чаевых.

💡 Подсказка

Внутри второй функции: s = total(...); return s * 1.1.

✅ Решение 
def total(price, count):
    return price * count

def with_tip(price, count):
    s = total(price, count)
    return s * 1.1

print(with_tip(250, 4))
06 Цепочка из трёх функций 🌱🌱🌱

first() возвращает 2. second() возвращает first() + 3. third() возвращает second() * 4. Вызови third().

💡 Подсказка

Каждая следующая вызывает предыдущую.

✅ Решение 
def first():
    return 2

def second():
    return first() + 3

def third():
    return second() * 4

print(third())
07 Своя программа 🌱🌱🌱

Придумай задачу, в которой нужны две функции: одна считает, другая решает. Например, перевод температуры: одна функция переводит, другая говорит «холодно/тепло/жарко».

💡 Подсказка

Структура: convert(...) возвращает число, verdict(...) вызывает её и возвращает строку.

✅ Решение 
def c_to_f(c):
    return c * 9 / 5 + 32

def verdict(c):
    f = c_to_f(c)
    if f < 50:
        return "холодно"
    elif f < 80:
        return "тепло"
    return "жарко"

print(verdict(20))
08 Найди и исправь 🌱🌱🌱

Программа должна вернуть результат вызова double(5) через функцию run(). Но функция run() забыла вызвать первую. Исправь.

💡 Подсказка

Внутри run() должно быть return double(n).

✅ Решение 
def double(n):
    return n * 2

def run(n):
    return double(n)

print(run(5))
