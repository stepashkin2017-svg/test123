⏱ 0–6 минут · 💌 Задача — рассылка

Байт получил список друзей

Соцсеть «Друзья Рядом» попросила Байта сделать приветственную рассылку. У Байта есть список друзей, и каждому нужно отправить личное сообщение.

🤖
Вот, смотри, список моих друзей: Аня, Боря, Вика, Гена. Каждому нужно написать «Привет, имя!». Как это сделать?

Можно написать четыре команды print() вручную. Пока друзей мало — сойдёт. А если их сто?

print('Привет, Аня!') print('Привет, Боря!') print('Привет, Вика!') print('Привет, Гена!')
🤖
Так не годится. Мне нужна такая команда, которая сама пройдёт по всем друзьям и каждому напишет сообщение. Одинаковый код — а работает с разными данными.

Такая команда есть — это цикл for. И сегодня мы его освоим.

💭 Знакомо?

На прошлом уроке мы изучили цикл while. Он повторяет действия, пока условие истинно.

Цикл for работает по-другому: он перебирает элементы последовательности один за другим. Где начало, где конец, в каком порядке — всё знает сам. Нам не нужен счётчик.

3 in — «в». Указываем последовательность.

⏱ 14–22 минут · 🔁 Синтаксис

Синтаксис цикла for

Разберёмся, как записывается цикл for и как его оформлять.

Цикл for
Это цикл, который перебирает элементы последовательности один за другим. Последовательность — это строка, список или другой упорядоченный набор.
for symbol in password: — перебрать все символы пароля.

Общая схема

for элемент in последовательность: действие_1 действие_2 действие_3 # это уже вне цикла
1 Служебное слово for.
2 Имя переменной — придумываем сами.
3 Служебное слово in и последовательность.
4 Двоеточие и тело цикла с отступом 4 пробела.
⚠️ Те же правила, что и раньше

1. После условия — двоеточие.
2. Тело цикла — с отступом в 4 пробела.
3. Команда без отступа — уже вне цикла.

Первое практическое применение

Давай выведем каждую букву слова на новой строке — но сначала спросим само слово.

word = input('Введите слово: ') for symbol in word: print(symbol)
Что выведет программа
Введите слово: мама
м
а
м
а

Как назвать переменную цикла

Имя переменной — наша фантазия. Обычно берут осмысленное: оно помогает понять, что в переменной лежит.

Имена друзейfriend, name

Что-то универсальноеitem, element

⏱ 22–32 минут · 🎯 Примеры

Разбираем примеры

Цикл for умеет не только печатать. Внутри цикла можно считать, искать и делать что угодно. Разберём три примера.

Пример 1. Считаем гласные

Программа перебирает буквы слова и считает, сколько среди них гласных. Гласные — «а», «е», «и», «о», «у», «ы», «э», «ю», «я».

word = input('Введите слово: ') vowels = 'аеиоуыэюя' count = 0 for letter in word: if letter in vowels: count += 1 print('Гласных:', count)
Что выведет программа
Введите слово: мама
Гласных: 2

Введите слово: программирование
Гласных: 7
🧠 Разбор

1. vowels — строка всех гласных букв.
2. count = 0 — счётчик до цикла.
3. Внутри цикла проверяем: буква входит в гласные? Если да — увеличиваем счётчик на 1.
4. После цикла печатаем результат.

Пример 2. Ищем запрещённые символы в логине

Это задача, которую поручила соцсеть. В логине можно использовать только буквы и цифры. Вот эти символы запрещены: = ? * ^ $ № @ _ , ; : # % &

login = input('Введите логин: ') wrong = '=?*^$№@_,;:#%&' for symbol in login: if symbol in wrong: print('Запрещённый символ:', symbol)
Что выведет программа
Введите логин: ps_smirnova
Запрещённый символ: _

Введите логин: p@vel_ivanov
Запрещённый символ: @
Запрещённый символ: _

Введите логин: anya2008
(ничего не выведет — все символы разрешены)

Пример 3. Считаем цифры в строке

Ещё один полезный пример. Программа считает, сколько в строке цифр — а сколько букв.

text = input('Введите текст: ') digits = '0123456789' count = 0 for symbol in text: if symbol in digits: count += 1 print('Цифр в тексте:', count)
Что выведет программа
Введите текст: у меня 3 кота и 2 собаки
Цифр в тексте: 2

⏱ 32–40 минут · 📋 Проверка логина

Решаем задачу соцсети полностью

Дополним проверку логина: если запрещённых символов нет — программа сообщает, что логин подходит.

🤖
Получается, цикл перебирает все символы, но как узнать, нашли мы что-то запрещённое или нет? Можно использовать переменную-флаг. Она как «лампочка»: горит — значит нашли проблему.
Переменная-флаг
Переменная, которая хранит True или False и показывает, случилось что-то важное или нет. Обычно заводят её до цикла.
ok = True — значит «всё хорошо». Если найдём проблему — поставим ok = False.
login = input('Введите логин: ') wrong = '=?*^$№@_,;:#%&' ok = True for symbol in login: if symbol in wrong: print('Запрещённый символ:', symbol) ok = False if ok: print('Логин подходит!') else: print('Логин содержит запрещённые символы.')
Что выведет программа
Введите логин: anya2008
Логин подходит!

Введите логин: p@vel_ivanov
Запрещённый символ: @
Запрещённый символ: _
Логин содержит запрещённые символы.
🧠 Разбор

1. Заводим флаг ok = True перед циклом — «пока всё хорошо».
2. Внутри цикла, если находим плохой символ — меняем флаг на False.
3. После цикла смотрим: если флаг всё ещё True — логин подходит. Иначе — нет.

Флаг удобен, когда нужно запомнить, произошло ли что-то важное во время цикла.

Задача: письмо друзьям

А теперь вернёмся к первоначальной задаче. Список друзей — это строка. Каждое имя мы будем перебирать в цикле. Правда, имена разделены пробелом, так что для простоты сделаем список друзей одной строкой с пробелами.

friends = 'Аня Боря Вика Гена' for friend in friends: print('Привет,', friend + '!')
Что выведет программа
Привет, А!
Привет, н!
Привет, я!
Привет,  !
Привет, Б!
…
🚨 Почему получились буквы?

Цикл for перебирает символы строки. А имена друзей — это слова, которые разделены пробелами. Пока мы работаем со строкой, цикл видит только отдельные буквы.

Чтобы перебирать слова, а не буквы, нужно превратить строку в список слов. Об этом — на следующем уроке, когда будем работать со списками.

💡 Что запомнить

Цикл for перебирает элементы той последовательности, которую мы указали. Если указали строку — перебирает буквы. Список слов перебирает слова — но списки мы ещё не проходили.

Итоговые задания в Playground

Восемь задач на цикл for и перебор строк. Нажми «Открыть в Playground» — стартовый код подставится сам.

Как работать. Открой задачу, напиши код, нажми Ctrl+Enter. Не забудь про двоеточие и отступ в 4 пробела.
01 Буквы слова 🌱

Спроси слово и выведи каждую букву с новой строки.

💡 Подсказка

for letter in word: — и внутри печатай letter.

✅ Решение 
word = input("Введите слово: ")
for letter in word:
    print(letter)
02 Сколько букв? 🌱

Спроси слово и посчитай, сколько в нём символов, используя цикл (без len()).

💡 Подсказка

Заведи count = 0. Внутри цикла count += 1.

✅ Решение 
word = input("Введите слово: ")
count = 0
for letter in word:
    count += 1
print("Символов:", count)
03 Гласные буквы 🌱🌱

Спроси слово и посчитай в нём количество гласных. Гласные: аеиоуыэюя

💡 Подсказка

Проверка: if letter in vowels:. Счётчик увеличиваем только в этом случае.

✅ Решение 
word = input("Введите слово: ")
vowels = "аеиоуыэюя"
count = 0
for letter in word:
    if letter in vowels:
        count += 1
print("Гласных:", count)
04 Запрещённые символы 🌱🌱

Спроси логин и выведи все запрещённые символы. Запрещены: =?*^$№@_,;:#%&

💡 Подсказка

Строку запретов сохрани в переменную. Внутри цикла проверяй if symbol in wrong:.

✅ Решение 
login = input("Логин: ")
wrong = "=?*^$№@_,;:#%&"
for symbol in login:
    if symbol in wrong:
        print("Запрещённый символ:", symbol)
05 Считаем цифры 🌱🌱

Спроси текст и посчитай, сколько в нём цифр.

💡 Подсказка

Строка всех цифр: "0123456789". Проверяй каждую букву через in.

✅ Решение 
text = input("Текст: ")
digits = "0123456789"
count = 0
for symbol in text:
    if symbol in digits:
        count += 1
print("Цифр:", count)
06 Проверка логина целиком 🌱🌱🌱

Спроси логин. Если в нём нет запрещённых символов — выведи «Логин подходит!», иначе — «Есть запрещённые символы».

💡 Подсказка

Используй флаг ok = True. Если находишь плохой символ — поставь ok = False.

✅ Решение 
login = input("Логин: ")
wrong = "=?*^$№@_,;:#%&"
ok = True
for symbol in login:
    if symbol in wrong:
        print("Запрещённый символ:", symbol)
        ok = False
if ok:
    print("Логин подходит!")
else:
    print("Есть запрещённые символы.")
07 Задом наперёд 🌱🌱🌱

Спроси слово и собери его обратную версию через цикл: перебирай буквы и добавляй их в начало новой строки.

💡 Подсказка

Заведи result = "". Внутри цикла result = letter + result — так каждая новая буква встаёт в начало.

✅ Решение 
word = input("Слово: ")
result = ""
for letter in word:
    result = letter + result
print("Задом наперёд:", result)
08 Найди и исправь 🌱🌱🌱

Программа должна вывести все буквы слова, но не работает. Найди ошибки.

💡 Подсказка

Проверь: есть ли двоеточие после in word? Есть ли отступ у print?

✅ Решение 
word = "мама"
for letter in word:
    print(letter)
