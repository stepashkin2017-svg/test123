⏱ 6–14 минут · 📋 Четыре отдельных if

Первое рабочее решение

Самое простое, что приходит в голову — сделать четыре отдельных условия. По одному на каждую строчку таблицы.

🤖
Я соединил пары условий через and. Если категория «молочные» и предпочтение «фермерское» — выдаю «Экоферма». И так для каждой строчки таблицы.
category = input('Категория товара: ') wish = input('Предпочтение: ') if category == 'молочные продукты' and wish == 'фермерское': print('Экоферма') if category == 'молочные продукты' and wish != 'фермерское': print('Моё село') if category == 'хлеб' and wish == 'цельнозерновой': print('Пекарня дяди Коли') if category == 'хлеб' and wish != 'цельнозерновой': print('Хлебозавод №21')

Матрёшка из условий

Как проверить категорию один раз, а уже внутри выбрать бренд? Разместить одно условие внутри другого.

Вложенный условный оператор
Это условный оператор внутри другого условного оператора. Сначала проверяется внешнее условие, и только если оно истинно — проверяется внутреннее.
Сначала проверяем категорию. Если она совпала — внутри проверяем предпочтение.

Код с вложенным условием

category = input('Категория товара: ') wish = input('Предпочтение: ') if category == 'молочные продукты': if wish == 'фермерское': print('Экоферма') else: print('Моё село') if category == 'хлеб': if wish == 'цельнозерновой': print('Пекарня дяди Коли') else: print('Хлебозавод №21')
Что выведет программа
Категория товара: хлеб
Предпочтение: цельнозерновой
Пекарня дяди Коли
🧠 Как это работает

Python сначала проверяет внешнее условие — категория. Если оно истинно, заходит внутрь и проверяет внутреннее — предпочтение.

Если внешнее условие ложно — во внутренний блок Python даже не заглядывает. Он пропускает его целиком и идёт дальше.

Оформление вложенности

Новых правил нет. Работают те же самые, что и раньше: двоеточие после условия и отступ в 4 пробела. Просто теперь отступов два уровня.

if выражение_1: if выражение_2: print(действие_1) else: print(действие_2) else: print(действие_3)
1 Внутренний блок — +4 пробела от внешнего.
2 Двоеточие после каждого условия.
3 else относится к ближайшему if.

Оператор с несколькими ветвями

Иногда условий становится очень много. Вкладывать их друг в друга неудобно. На этот случай есть третий способ — elif.

🤖
Я делал программу для интернет-магазина с акцией «Счастливые часы». Если покупают с 10 до 12 — скидка 50%, с 20 до 22 — 75%, в остальное время — без скидки. Я написал через составное условие, но получилась очень длинная проверка. Как её упростить?

Задача «Счастливые часы»

Плохое решение — всё в одном составном выражении:

total = int(input('Сумма: ')) time = int(input('Текущее время (час): ')) if time >= 10 and time <= 12: total = total / 2 print('Акция! Итого к оплате:', total) if time >= 20 and time <= 22: total = total / 4 print('Акция! Итого к оплате:', total) if time >= 0 and time < 10 or time > 12 and time < 20 or time > 22 and time <= 24: print('Итого к оплате:', total)

Последнее условие — просто монстр. Три части, куча and и or. Легко ошибиться.

elif
Сокращение от «else if» — «иначе если». Позволяет проверить следующее условие, только если предыдущее было ложным. Ветвей может быть сколько угодно.
Программа идёт по ветвям по порядку. Как только нашла истинное условие — выполнила действие и вышла из всей конструкции.

Как выглядит elif

if выражение_1: действие_1 elif выражение_2: действие_2 elif выражение_3: действие_3 else: действие_для_всех_остальных

Читается так:

1 Если выражение_1 истинно → выполнить действие_1.
2 Иначе если выражение_2 истинно → действие_2.
3 Во всех остальных случаях → выполнить else.

«Счастливые часы» через elif

total = int(input('Сумма: ')) time = int(input('Текущее время (час): ')) if time >= 10 and time <= 12: total = total / 2 print('Акция! Итого к оплате:', total) elif time >= 20 and time <= 22: total = total / 4 print('Акция! Итого к оплате:', total) else: print('Итого к оплате:', total)
Что выведет программа
Сумма: 1700
Текущее время (час): 21
Акция! Итого к оплате: 425.0

Сумма: 1000
Текущее время (час): 15
Итого к оплате: 1000

То же самое, что раньше, но код стал короче и понятнее. Ветка else сработает во всех остальных случаях — не нужно перечислять их через or.

🧠 Порядок проверки важен

Программа проверяет условия сверху вниз и останавливается на первом истинном. Все следующие ветви даже не проверяются.

Поэтому важно располагать условия в правильном порядке.

⏱ 32–40 минут · ⚖️ Какой способ лучше

Три способа записать одно и то же

Одну задачу можно решить по-разному. У каждого способа есть свои плюсы. Разберём на примере.

🤖
Задача: покупатель вводит «Завтрак» — предлагаем кашу. «Обед» — суп с тефтелями. Всё остальное — блины с рыбой. Смотри, как по-разному это можно записать!

Способ 1. Через составное условие

Составное условие
meal = input('Приём пищи:')

if meal == 'Завтрак':
    print('Каша')

if meal == 'Обед':
    print('Суп с тефтелями')

if meal != 'Завтрак' and meal != 'Обед':
    print('Блины с рыбой')
Вложенный if
meal = input('Приём пищи:')

if meal == 'Завтрак':
    print('Каша')
else:
    if meal == 'Обед':
        print('Суп с тефтелями')
    else:
        print('Блины с рыбой')
elif — самый чистый
meal = input('Приём пищи:')

if meal == 'Завтрак':
    print('Каша')
elif meal == 'Обед':
    print('Суп с тефтелями')
else:
    print('Блины с рыбой')

Все три способа работают одинаково. Но у них разные плюсы:

СпособКогда удобен
Составное условие Когда условий всего 2–3 и они простые
Вложенный if Когда условия зависят друг от друга — второй признак имеет смысл только после первого
elif Когда вариантов много, и все на одном уровне
🧠 Как выбрать способ

1. Если условия независимы — используй отдельные if или elif.
2. Если второе условие имеет смысл только при первом — вкладывай одно в другое.
3. Если вариантов много, и они как цепочка — elif обычно самый читаемый.

Задача: рекомендация еды

Байт приготовил ещё одну задачу. Если клиент вводит «Завтрак» — рекомендуем кашу. Для других приёмов пищи уточняем: хочет ли клиент поесть плотно. Если да — плов, если нет — котлета с пюре.

Здесь вложенность нужна — второй вопрос имеет смысл только после ответа на первый.

meal = input('Приём пищи: ').lower() if meal == 'завтрак': print('Каша') else: wish = input('Предпочтение: ').lower() if wish == 'поесть плотно': print('Плов') else: print('Котлета с пюре')
Что выведет программа
Приём пищи: обед
Предпочтение: поесть плотно
Плов

Приём пищи: завтрак
Каша
⚠️ В чём ошибка такого подхода

Если покупатель введёт что-то странное — например, категория «хлеб» и предпочтение «с семечками» — программа всё равно что-то посоветует. Иногда это неверно.

В реальных проектах программисты добавляют ещё один else для «непонятных» случаев, чтобы честно сказать: «Я не знаю, что вам предложить».
